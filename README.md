## Escenario elegido
Escenario B - Análisis de Ventas de una Pequeña Empresa

## Descripción del proyecto
Este proyecto fue desarrollado utilizando Git, GitHub, Jira y Google Colab.

El objetivo consiste en analizar un conjunto de datos de ventas comerciales utilizando Python para generar indicadores básicos y gráficos estadísticos.

## Estructura del repositorio

- datos/: contiene el dataset CSV
- scripts/: contiene el script Python
- resultados/: contiene gráficos generados automáticamente

## Funcionalidades del script

El script permite:
- leer datos desde un archivo CSV
- calcular ventas totales
- identificar el producto más vendido
- generar gráficos de ventas

## Tecnologías utilizadas

- Python
- Pandas
- Matplotlib
- Git
- GitHub
- Jira
- Google Colab

## Ejecución

Ejecutar el siguiente comando:

```bash
python scripts/analisis_ventas.py
```
